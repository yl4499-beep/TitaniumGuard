## 关于赛题匹配

氧含量散点图提供环境参数与试样强度的描述性关系。数据生成器同时植入了氧含量升高和强度下降，因此不能把分组差异解释成氧含量的因果效应。激光功率、扫描速度和热处理等仍作为记录背景，没有拟合成预测模型。试样极限抗拉强度也不等于成品支架的载荷试验或疲劳寿命预测；这一范围限制已经在 README 说明。
