## 本次实际发现并修复的问题

| 问题 | 原先行为 | 修订后行为 |
|---|---|---|
| API 数字类型 | true 可被当作数值1，数字字符串被自动转换 | 规格参数要求真正的有限正数；布尔值和数字字符串明确报错 |
| API 参数拼错 | targte 被忽略，继续使用默认 target | 未知参数返回422，提示具体字段 |
| 非法数字的错误响应 | 某些 NaN/Infinity 请求触发500 | 返回可读的422 JSON，错误响应不回显原始输入 |
| 数据列名拼错 | machine_id 后多一个空格会被忽略，可能漏掉混合设备 | CSV 和 JSON 未知字段明确报错，避免静默丢失信息 |
| ID、文字字段类型 | 布尔值、列表、对象可能被转换为文字后接受 | 标识符、时间和文字元数据要求字符串 |
| CSV 换行 | 旧式 CR 换行文件不能读取 | LF、CRLF、CR 均通过验证 |
| API 文档的外部依赖 | 外部资源无法加载时，Swagger 文档打不开 | JS/CSS 与项目一起提供；禁止外网时仍能执行接口 |
| 未应用的参数 | 参数输入框可能与当前显示结果不一致 | 显示待应用提示，在成功计算前暂停导出和新增记录 |
| 手动录入时间 | 表单没有说明使用哪个时区 | 显示当前数据的时区，并保留声明的 UTC 偏移 |
| 模拟数据混用提示 | 加入手工记录后，模拟数据提示不够明确 | 保留模拟数据提醒，说明应导入自己的真实基线 |

## 使用范围与当时尚未验证的部分

- 输入为按时间排列、每批2–10个且批间数量相同的独立强度测试结果。不会自动补齐缺失批次或混合不同设备、热处理路线。
- 三套演示数据是模拟数据；900 MPa 和1.33是教学设置，不是航空技术标准。
- 这是过程监控与调查辅助原型；不预测每个零件的失效，也不批准零件放行。
- 当前记录保存在浏览器标签页内，没有账户、多用户数据库或持久化审计记录；离开前必须导出CSV。程序会提示这一点。
- 在 2026-10-20 审计时，实际课程服务器上的 Python 兼容性、发布权限、公开访问和运行表现尚未验证；后续上线验证见 DEPLOYMENT.md。部署包本地通过不能替代真实服务器验证。
- 该审计时点尚无 Git commit 历史、公开仓库、GitHub Actions 实际运行记录、正式线上地址或 Devpost 提交记录；后续 GitHub 和部署工作已经完成。预览HTML只展示预先算好的结果，完整计算由Python应用提供。
