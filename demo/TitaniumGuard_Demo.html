What was verified, and what remains

The statistical core passed 50 numerical and boundary tests, plus an independent read-only formula review. Nine API integration checks also passed. The full app, tests, synthetic data generator, codebook, English presentation script and Chinese guide are in the project package.

Run bash app/testme.sh from the unzipped project to open the full application. Publishing the public GitHub repository, deploying to the course Posit Connect account and submitting on Devpost require actual account access; this preview is not evidence of those actions.
